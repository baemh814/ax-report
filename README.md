# 📰 AX 트렌드 리포트 (The AI · AX Chronicle)

사내 AX(인공지능 전환) 추진 리더 및 임직원을 위한 엔터프라이즈 AI 전문 주간 큐레이션 웹 리포트입니다.

---

## 📁 핵심 파일 구성 안내

| 파일명 | 역할 및 설명 |
| :--- | :--- |
| **`index.html`** | 리포트의 전체 화면 레이아웃 및 텍스트 구조 (클래식 모던 신문 톤앤매너) |
| **`styles.css`** | 신문 풍 타이포그래피, 헤드라인, 2열 아티클, 반응형 디자인 스타일 시트 |
| **`app.js`** | 카테고리 필터링, 검색, 아젠다 탭 전환, 주간 캘린더 등 인터랙션 로직 |
| **`news.json`** | 현재 화면에 표시되는 실제 뉴스/리포트 원본 데이터 (JSON 포맷) |
| **`update_news.py`** | 한국경제, 매일경제, 글로벌 컨설팅 RSS를 자동 수집하고 Gemini AI로 요약하는 파이썬 파이프라인 |
| **`requirements.txt`** | 파이썬 크롤링 파이프라인 실행에 필요한 라이브러리 목록 |
| **`DEPLOY_GUIDE.md`** | GitHub Actions 및 GitHub Pages 무료 자동 배포 설정 가이드 |

## 💻 회사 클라우드 PC(사내망)에서 작업하는 방법

본 웹사이트는 별도의 복잡한 백엔드 서버 없이 **HTML + CSS + JavaScript** 순수 웹 기술로 제작되어 있어 사내망에서도 완벽하게 동작합니다.

### 1. 화면 즉시 확인 (로컬 실행)
* **가장 쉬운 방법**: `index.html` 파일을 더블 클릭하여 브라우저(Edge, Chrome 등)로 엽니다.
* **VS Code 추천**: VS Code 확장 프로그램인 **Live Server**를 설치하고 하단 `Go Live`를 누르면 코드를 수정할 때마다 화면이 실시간으로 새로고침됩니다.

### 2. 콘텐츠 및 디자인 수정
* **UI 레이아웃 및 텍스트 문구**: `index.html` 수정
* **디자인/폰트/색상/여백**: `styles.css` 수정
* **새로운 리포트 수동 추가**: `news.json` 파일의 `articles` 배열에 새로운 뉴스 객체를 규격에 맞게 추가하면 화면에 즉시 반영됩니다.

## 🔄 회사 PC ↔ 외부 배포 연동 루틴

회사 클라우드 PC가 외부 인터넷(GitHub)과 직접 통신할 수 없는 보안망인 경우:

1. **회사 PC에서 작업**: `index.html`, `styles.css`, `app.js`, `news.json` 등을 자유롭게 수정하고 검토합니다.
2. **작업물 반출**: 수정한 파일들을 사내 망연계(파일 반출) 또는 메일로 개인 PC로 보냅니다.
3. **GitHub 푸시 & 배포**: 개인 PC의 작업 폴더에 덮어쓴 뒤 `git push`를 실행하면 GitHub Pages를 통해 전 세계 웹에 즉시 최신 상태로 배포됩니다.
